The trainer's path through a drill: set it up before the meeting, reset it, say GO, watch it, finish with the hot wash. The other tabs hold every detail.

  1. 1. Before the meeting: set up and rehearse

    Rehearse if you like: GO at 10× for a few minutes shows every path. The reset below clears it from the EOC (Emergency Operations Center).

  2. 2. Reset for the session

    Stops whatever ran before and keeps it as a rehearsal, opens a fresh drill event on the EOC (no rehearsal traffic; the SITREP (situation report) clock starts at GO), plans the same run again at T+0, sets the PACE level (Primary, Alternate, Contingency, Emergency) to the scenario's first one. Every EOC screen then shows ready: waiting for the trainer's GO.

        Log

        What the EOC must do about what the simulator sent: every work item it posts, every work item the EOC derives from a simulated report, every paper or net report a person must type in. Each need has a deadline in drill minutes; the simulator reads the EOC every few seconds. An overdue need triggers its consequence (the caller comes back, the truck stays put); a met need triggers the resolution (approval, thanks, truck ETA, estimated time of arrival). Nothing here is sent to the players: it is the controller's ledger.
