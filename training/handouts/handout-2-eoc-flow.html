The EOC: every report in one picture

An EOC (Emergency Operations Center) runs the Message Center on one Windows laptop, open in every operator's browser on the EOC Wi-Fi. Reports file themselves, their work is listed, and the SITREP (situation report) goes up the chain. Experimental: tested on two laptops, not yet in a full drill. Tell us what you find.

1Set up this EOC (Overview checklist)

  1. Start the EOC Server (Desktop); keep its window open.
  2. Name this EOC, the EOC above and its units.
  3. Open the event: it starts now, units on its roster.
  4. Set the PACE level (Primary, Alternate, Contingency, Emergency).
  5. Choose the Winlink callsign whose mail feeds this EOC.
  6. Fill in or load the Comms Sheet.

2During the event

  • Missionary bar: no answer is not the same as safe.
  • Work Items: owner, status, decision. A follow-up updates them.
  • SITREP: the first assessment as soon as possible, then on the interval EOC leadership sets.
  • Supply Orders: the ERD (Emergency Response Director) and the welfare line approve; the Bishops' Storehouse fills them.

3Who decides

The stake Welfare and Self-Reliance Specialist (emergency communications) recommends the PACE level; the Stake President decides; the ERD or the specialist announces it.

Welfare line: WSRM (Welfare and Self-Reliance Manager), then AWSRM (Area Welfare and Self-Reliance Manager). Council line: Area Seventy.

4What an EOC needs

  • A Windows laptop, Python 3.8+, Winlink Express (and the VARA radio modem).
  • The installer, option [3] EOC Operator.
  • Wi-Fi set to Private; press Allow when asked.
  • Optional: a TV for the wall display.
