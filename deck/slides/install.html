Installation Guide

Four components to set up — most roles need only one or two

A

Worker Forms

For: all volunteers

  1. Open the portal URL or scan the QR poster
  2. Add to Home Screen: the Church of Jesus Christ EMCOMM app, which then works with no signal
  3. Fill one practice form; Save to Outbox, then Send
  4. Print 3 blank paper forms for the go-bag

Time: 5 minutes

No app store, no account

B

Winlink Templates

For: HAM operators

  1. Install Winlink Express (winlink.org)
  2. Run the installer → [2] HAM Field Operator
  3. It copies 3 .txt templates + HTML forms into Global Folders\Templates\Church of Jesus Christ EMCOMM Forms\, and 7 pre-filled practice forms (THIS IS AN EXERCISE ticked) into …EMCOMM Practice\
  4. Restart Winlink; verify under New Message → Select Template → Global Templates
  5. A training copy of the practice forms goes to Documents\…\Training\

Time: 15 minutes

Requires Winlink Express

C

EOC Message Center

For: Satellite, Stake and Council / Area EOC operators

  1. Install Python 3 (free — microsoft.com/store)
  2. Run the installer → [3] EOC / Stake Operator
  3. Double-click Church of Jesus Christ EMCOMM EOC Server on the Desktop; note the URL it shows
  4. Other operators open that URL in any browser
  5. Setup tab → EOC level (Satellite / Stake / Area), name, units, parent EOC, the must-have roles, the Map data folder; open the Emergency Event
  6. Test: drop a .txt in the EOC Drop Folder and a .mime from Winlink
  7. Any other device: a browser, nothing to install (hosting and Winlink need Windows)

Time: 25 minutes

Requires Python 3 + any browser · 🟢 networked / 🟡 standalone

D

Radio Setup

For: EMCOMM operators (Contingency)

  1. Install VARA FM (downloads.winlink.org — free at reduced speed; a one-time license unlocks full speed)
  2. Connect the VHF/UHF radio to the PC by audio cable; set the COM (serial) port and audio device
  3. Winlink: Open Session → VARA FM Winlink; test the nearest RMS gateway
  4. Program the stake voice net (repeater + simplex)
  5. For HF: install VARA HF and the HF interface

Time: 2–4 hours first time

Requires: Technician+ (General+ for HF)

Free software, no admin rights. The installer asks your role and puts the Quick Reference Cards on the Desktop

The installation sequence should be done in advance of any emergency. Components A and C can be set up in under 30 minutes total. Component D (radio setup) takes longer but only needs to be done once per station, and it is what makes the Contingency level real.
