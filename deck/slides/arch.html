Two doors into the EOC: Drop Folder (P / A) and Winlink (A Telnet, C radio). The same Winlink reaches the welfare line at every level

The key architectural insight: two parallel paths into the EOC. Path A (radio): volunteers → HAM operator loads .txt into Winlink → sends by radio → EOC auto-ingests from Winlink Received folder. Path B (internet): volunteers → email/text/AirDrop .txt to EOC operator → operator saves to EOC Drop Folder → auto-ingested within 10 seconds. Both paths produce identical records in the EOC. Radio is the primary path when cell/internet is down; internet path is faster when connectivity is available. The chain is field → Satellite EOC → Stake EOC → the council line (Area Seventy) and the welfare line (WSRM, AWSRM): the same Message Center at a Satellite EOC rolls up to the Stake Center, and the Stake EOC rolls up to the Council / Area EOC when the council or welfare region opens one — see the EOC topology slide.
