PACE: C · CONTINGENCY

All Local Infrastructure Gone

HF Radio — When No Local Gateway Answers

When VARA HF Applies

  • Regional disaster — all cell towers and internet down
  • No VHF/UHF gateway within range
  • Large-scale event (earthquake, hurricane, flood)
  • Can still reach Winlink HF gateways nationwide

HF Connection Modes

  • VARA HF — free, fast, software-only (recommended)
  • Pactor 4 — fastest, but $1,000+ modem
  • ARDOP (Amateur Radio Digital Open Protocol) — free, slower fallback built into Winlink Express
  • Typical speed: 40–4,000 bps; a full report is under 2 KB

Data Entry over HF

No working devices: HAM operator uses paper Church forms and types the data into the Winlink template — every field accepts manual entry. Devices but no file transfer: the volunteer reads the fields over FRS/GMRS or the stake net and the operator types them in. All of this is still Contingency; Emergency begins only when HF fails too.

Minimum Equipment

  • HAM station: PC + Winlink + HF transceiver (100W, 40/80m) + antenna + VARA HF or Pactor modem
  • License: General or Amateur Extra (HF privileges)
  • Power: battery + solar or generator backup
  • EOC: same HF setup, or any working internet

Below HF: PACE Emergency

HF is the last radio path. If it fails too, the field goes to paper and runners, and the Stake EOC reaches the lines above through the stake liaison at the county EOC (county Starlink or satellite phone) or by courier. Queued Winlink messages go out the moment any path returns.

Forms and Message Center unchanged over HF — compact machine tags send a full Disaster Report in seconds at HF speeds

VARA HF is — the last radio path, still inside PACE Contingency. The machine-readable format of our forms is a key advantage here: a full disaster report with all fields fits in under 2 kilobytes. The same HF path carries the SITREP up to the welfare line, and because the Winlink CMS holds the message, the welfare line can read it by internet. Below HF is Emergency: a runner with a paper form, or the stake liaison passing the SITREP through the county EOC.
