Readiness

Pre-Event Deployment Checklist

Volunteers Ready

The app installed on personal phones; blank forms in the go-bag

Test save and share completed at least once

QR code printed for each form at site entry

Paper backup forms available at each site

HAM Station Ready

Winlink Express installed and licensed

Church of Jesus Christ EMCOMM templates in correct folder

Test Load Data + Submit with a real .txt file

VARA FM configured and gateway connection tested

USB drives with worker forms on hand

Nearest VHF/UHF and HF RMS gateways identified

Stake voice net (repeater + simplex) and ward FRS/GMRS channels programmed

EOC Ready — Satellite · Stake · Area

EOC Message Center on USB drive (labeled)

Setup tab configured with stake info

Test .mime drop: verify all 3 form types parse

SITREP generator tested end-to-end

Shift handoff export/import verified

Council line and welfare line addresses tested; county EOC liaison named

Stake PACE sheet filled in and printed (docs/PACE_PLAN.md)

Council / Area EOC, if opened: level set, every stake’s drop email and Winlink address on file, one roll-up merged

Annual Drill

Full end-to-end test: Worker Form → Winlink → EOC → welfare line

Drill every PACE level: Wi-Fi only (A), radio only — VARA FM + FRS/GMRS voice (C), runner (E)

Time each step — identify bottlenecks

After-action review and update procedures

A system that has never been drilled will fail when it is needed most — test every component before the event

The checklist is the readiness gate. None of it is complicated, but all of it needs to be done in advance. The worst time to find out that the VARA FM gateway connection doesn't work is during an actual disaster.
