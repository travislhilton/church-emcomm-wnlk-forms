EMCOMM Operator Role

HAM Operator Process

The radio bridge between field teams and the Stake EOC — and the EOC’s bridge to the Area at Contingency

1 · Create the Form in Winlink Express

  • New Message → Select Template → Global Templates → Church of Jesus Christ EMCOMM Forms → choose the form (DR / SO / WCL)
  • Fill it in from the voice report on the net, the paper form or the person in front of you; your callsign and station location auto-fill. Save Data keeps a copy
  • Drill or training? Tick THIS IS AN EXERCISE (red box at the top): banner in the message, EXERCISE chip at the EOC

2 · Or Load a Volunteer’s File

  • Receive the .txt file by text / email (P, A) or AirDrop / Nearby Share / USB (C)
  • Same template → Load Data → select the file → every field fills in. Review; add anything missing
  • To practice: EMCOMM Practice has 7 pre-filled exercise forms — select one, Submit, send it to your EOC

3 · Send by the PACE Level in Force

  • Click Submit — creates a Winlink message in the Outbox. Address it to your EOC’s Winlink address from the stake Comms Sheet
  • Open Session: A Telnet (any internet) → C VARA FM Winlink (VHF/UHF) → C VARA HF (no local gateway)
  • Verify sent; confirm receipt with the EOC on the net

PACE rule: step down after two failed attempts in 15 min or when the Stake President decides it (the ERD or the specialist announces it on the net); step back up only after a test message round-trips. Announce the level at every check-in.

Install Path

C:\RMS Express\Global Folders\Templates\
Church of Jesus Christ EMCOMM Forms\
Church of Jesus Christ EMCOMM Practice\

3 .txt definitions + HTML forms, 7 practice forms — the installer puts them there. Not Standard Templates (overwritten by Winlink updates).

At the EOC Station

  • Run the Church of Jesus Christ EMCOMM EOC Server shortcut
  • Church form Winlink messages auto-ingest within 10 s; emailed forms via the EOC Drop Folder
  • Status badges: NEW → ACK → ASSGN → DONE
  • SITREP from the DR tab; send up to the council line and the welfare line by email (P/A) or Winlink radio (C); level in force in the header

Keep a Log

Time sent, form type, originating address, Winlink message ID, level in force. The Message Center captures this; the paper log is the backup.

Training time for HAM operators: 2–4 hours hands-on filling the templates, Load Data, and switching Telnet → VARA FM → HF

The HAM operator is the critical link in the system. Every drill message must carry THIS IS AN EXERCISE: the box at the top of each form puts a banner in the message, a prefix in the subject and an exercise tag in the data, and the EOC marks the report as an exercise. The seven practice forms under EMCOMM Practice are already ticked and filled from the simulator's earthquake scenario, so a new operator can send a realistic exercise message in a minute. The most important thing to practice is creating a form in the Winlink template from a report given by voice or on paper and submitting it; then loading a volunteer's .txt file with Load Data, reviewing it and submitting; and then switching the session type by PACE level: Telnet at Alternate, VARA FM at Contingency, HF when no local gateway answers. Do this in a drill before any real event.
