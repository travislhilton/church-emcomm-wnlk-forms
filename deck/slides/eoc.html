EOC Levels — Same Software

Satellite EOC (optional)

Ward building; covers assigned wards. Rolls up to the Stake EOC.

Stake EOC

One per stake. The Stake President directs; the ERD runs it. Tracks ward reports; sends up to the council line and the welfare line.

Council / Area EOC (only if opened)

Only if the council or welfare region opens one; merges stake roll-ups. Otherwise stakes send to the two lines above them (council, welfare).

Minimum Hardware

  • Windows 10/11 laptop (i3, 8 GB RAM)
  • Python 3 (free)
  • USB audio interface (~$40) for radio
  • UPS (uninterruptible power supply) or battery backup
The EOC has two modes: Networked (Python server running, SQLite database, all operators share one view) and Standalone (single HTML file, in-memory only). In networked mode, TWO auto-ingest watchers run: (1) Winlink watcher reads the chosen callsign's received messages in C:\RMS Express\\Messages every 10 seconds (only those since the event began) and ingests the Church forms, leaving Winlink's mail untouched; the callsign is chosen once on the watcher bar and saved for every start; (2) Internet Drop Folder watcher polls Documents\Church of Jesus Christ EMCOMM\EOC Drop Folder\ every 10 seconds, ingests Worker Form .txt JSON files from any delivery method (email, text, AirDrop, USB). Both paths produce identical EOC records. Status badges cycle through NEW → ACK → ASSIGNED → DONE and sync in real time. Shift handoff is Export All → USB → Import on the next operator's browser. The same Message Center runs at a Satellite EOC in a ward building, at the Stake Center, and at the Council / Area EOC when the council or welfare region opens one; the Setup tab sets the level and the parent, and roll-ups move up the chain on the next slide. The Setup tab also flags the roles that must be filled before the EOC is real, and takes the folder of the Church directory export so the Map tab and the wall can draw the wards coloured by roster status; that folder never leaves the laptop. Reports sent with THIS IS AN EXERCISE ticked carry EXERCISE chips, and the wall shows an EXERCISE badge when every report on file is one.
